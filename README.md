## Why this exists

Tutorials show the clean version. Streams show the real one.

This repo holds the full source for every project we build on stream: the wrong turns, the fixes, the final result. Clone it, run it, break it, make it yours.

## Quickstart

```bash
git clone https://github.com/zerotraceacademy/projects.git
cd projects
```

Pick a project folder, then follow the `README` inside it.
